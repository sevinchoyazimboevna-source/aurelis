4. **Final Office schema:** One `offices` collection with timestamps. Fields: `_id`, name, slug, status, country, city, addressLine1, addressLine2, postalCode, phone, email, timezone, embedded businessHours, shortDescription, description, heroImage, images, featured, sortOrder, createdAt, updatedAt. Required name/country/city/slug lengths 1–120; addressLine1 1–240. Defaults DRAFT/false/0 and empty image/hour arrays. No parallel location model.
5. **OfficeStatus:** DRAFT, PUBLISHED, ARCHIVED.
6. **DayOfWeek:** MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY.
7. **Slug:** One normalizeOfficeSlug helper at service boundary; generated from name when omitted on create. Trim, accent decomposition, lowercase, normalize whitespace/repeated hyphens. Explicit unsafe URL characters rejected; ASCII alphanumeric hyphen-separated output, maximum 120. Global uniqueness precheck plus unique-index race mapping to BadRequestException. Name-only update preserves slug; explicit updates exclude current record from uniqueness check. No suffixes or redirect history.
8. **Country/city:** Required trimmed nonblank display/search strings, maximum 120. No geographic models, Destination inference, hardcoded offices or seeded content.
9. **Address:** Required trimmed addressLine1; optional addressLine2 (maximum 240) and postalCode (maximum 40). No external normalization.
10. **Contact:** Optional phone (trimmed nonblank display string, maximum 80), email (trim/lowercase and existing IsEmail validation). Public business information only. No email sending, SMS or authentication configuration exposure.
11. **Timezone:** Optional string, trimmed, maximum 120 at input. Semantic runtime Intl.DateTimeFormat validation; supported identifiers/aliases depend on Node ICU data. No conversion service or host-local-time dependency in tests.
12. **Hours structure:** One embedded array, maximum seven entries, without subdocument IDs. Each entry has day, nullable/optional openTime/closeTime and closed (default false). Empty array allowed.
13. **Hours validation:** Unique weekday; open days require HH:mm (00:00–23:59), openTime < closeTime. Equal/reversed hours rejected. Closed days require absent/null times. Full supplied schedule validated before create/update, then replaced atomically as a field. No split/overnight/holiday scheduling.
14. **GraphQL Office:** Exposes precisely the fields in item 4, with embedded OfficeBusinessHours. Required businessHours/images arrays and timestamps; optional presentation/contact fields nullable. No populated auth or database internals.
15. **Wrapper:** Offices { list: [Office!]!, total: Int!, page: Int, limit: Int, totalPages: Int }. Existing Yachts total remains Float.
16. **Filters:** OfficeFilterInput status, country, city, featured, search inside OfficeCatalogInput. Public status is independently overridden; admin may filter all statuses.
17. **Search:** Escaped literal case-insensitive substrings in name/country/city. Country/city filters are escaped whole-string case-insensitive matches. No external search system.
18. **Sorts:** FEATURED = featured descending, sortOrder/name/_id ascending; SORT_ORDER = sortOrder/name/_id ascending; NAME_ASC/DESC = corresponding name order with ascending _id; NEWEST = createdAt/_id descending. Deterministic secondary ordering; MongoDB default case-sensitive name collation. sortOrder defaults 0, integer >=0, nonunique.
19. **Pagination:** Defaults page 1/limit 20; maximum 50; validated integers with page/limit >=1. MongoDB aggregation $match/$sort/$facet, list $skip/$limit and independent total $count. totalPages = ceil(total/limit); zero for empty results. No in-memory production pagination.
20. **getOffices:** Required OfficeCatalogInput; public collection always PUBLISHED, with shared filtering/sorting/pagination.
21. **getOffice:** Required slug; normalized lookup always PUBLISHED. No ambiguous ID fallback. Missing/unpublished detail throws existing NotFoundException.
22. **getFeaturedOffices:** Optional input; always PUBLISHED and featured=true, even when contradictory filters are supplied. Same wrapper and deterministic defaults.
23. **Admin query:** getOfficesForAdmin requires active ADMIN via existing AuthGuard/RolesGuard; can read/filter DRAFT/PUBLISHED/ARCHIVED.
24. **Create:** createOffice requires ADMIN, validates fields/hours/slug uniqueness and persists safe defaults. No automatic Aurelis name prefix.
25. **Update:** updateOffice requires ADMIN and valid _id; existing record check; only defined supplied fields reach $set with runValidators. Name-only changes preserve slug; supplied hours are complete replacements. Explicit zero/false/[] supported. Optional mutation nulls rejected; closed-day time nulls are allowed.
