Member/Yacht/Destination references use BSON ObjectIds. No reverse references.
5. **ArticleType:** NEWS, INSIGHT, GUIDE only, registered as GraphQL ArticleType.
6. **ArticleStatus:** DRAFT, PUBLISHED, ARCHIVED only, registered as GraphQL ArticleStatus.
7. **Slugs:** Single helper trims, folds accents, lowercases and joins spacing with hyphens. Generated titles discard punctuation; explicit slugs reject unsafe characters. Maximum 200; globally unique across statuses. Preflight checks and duplicate-index race handling use BadRequest. Title-only updates preserve slugs; explicit changes have no redirect history.
8. **Excerpt/content:** Trimmed simple strings, excerpt optional up to 1,000 characters; content optional for drafts, nonblank for a merged PUBLISHED state, up to 200,000. No generation, parsing, rich text or sanitizer infrastructure. Images use trimmed path/URL strings up to 2,048 characters per entry.
9. **Author:** Optional trimmed authorName up to 120 characters and optional existing Member ID. Any existing role is permitted for admin-curated metadata. No credentials, role mutation, account creation or authorization follows from linking.
10. **Featured:** Defaults false. Public featured reads independently force true plus shared visibility; caller featured=false cannot bypass it.
11. **publishAt:** Optional valid Date requesting public availability; future timestamps hide PUBLISHED records. Query-driven, no scheduler/status flip. Mutation null is rejected; omission preserves the value.
12. **publishedAt:** Not writable through GraphQL inputs. Set once at create-PUBLISHED or first transition to PUBLISHED if missing, including future schedules. It records first PUBLISHED transition, not measured actual scheduled release time. Preserved through later edits, schedule changes, draft/archive and republication. Conditional first-stamp write prevents competing publications replacing an existing stamp.
13. **Yacht links:** Optional distinct valid existing IDs of any status; duplicates rejected case-insensitively by ObjectId identity. Omission preserves; [] clears. No Yacht writes or reverse links.
14. **Destination links:** Same supplied-array validation and update rules as Yacht links, including any status. No Destination writes or reverse links.
15. **GraphQL Article:** `_id: ID!`, title/slug String!, type/status enums!, excerpt/content/coverImage/authorName nullable String, authorMemberId nullable ID, images [String!]!, featured Boolean!, publishAt/publishedAt nullable DateTime, yachtIds/destinationIds [ID!]!, createdAt/updatedAt DateTime!. No nested linked entity or Member auth object.
16. **Wrapper:** `Articles { list: [Article!]!, total: Int!, page: Int, limit: Int, totalPages: Int }`. Legacy Yachts Float total remains untouched.

18. **Search:** Trimmed, maximum 200; escaped case-insensitive literal substring regex on title/excerpt/authorName. Search OR is inside a separate AND and cannot replace the availability OR.
19. **Sorts:** NEWEST createdAt/-_id descending; OLDEST createdAt/_id ascending; TITLE_ASC title/_id ascending; TITLE_DESC title descending/_id ascending; PUBLISHED_NEWEST publishedAt/_id descending; FEATURED featured/publishedAt/_id descending.
